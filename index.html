Flight systems

01 / What I test, layer by layer

Most bugs that reach production were visible one layer below where anyone looked. Every release gets checked on four systems.

S-01 · Web / UI

What users touch

  • ExploreFunctional, exploratory and cross-browser runs on forms, search, cart and checkout.
  • AutomateEnd-to-end suites built on the Page Object Model.
  • GateRegression on every build, with reports people read.
Playwright · TypeScript · GitHub Actions
S-02 · API

What the UI hides

  • ExploreStatus codes, payloads, auth and negative cases, straight at the endpoint.
  • AutomateRequest collections and API checks in the same suite.
  • GateContract checks that fail fast, before UI tests start.
Postman · Playwright request
S-03 · Data

What actually got saved

  • ExploreSQL queries that confirm records match what the app claims.
  • AutomatePipeline checks for accuracy, consistency and integrity.
  • GateData checks after orders, payments and other critical flows.
SQL · Python · Pytest
S-04 · AI / LLMFocus

Whether the answer is true

  • ExploreAdversarial prompts, hallucination and misclassification probes.
  • AutomateScored checks for grounding, consistency and relevance.
  • GateRegression against the last good model or prompt.
Python · LLM evals · CI
